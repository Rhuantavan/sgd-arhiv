Nalaganje nastavitev iz tekstovne datoteke

Avtor: napsy
Objavljeno: 20.01.2003, ob 23:07:38.


Torej, naredili ste program, ki zahteva nastavitve od uporabnika. Sedaj pa ľelite, da se te nastavitve shranijo in da uporabnika ob ponovnem zagonu programa ni potrebno ponovno motiti z nastavitvami. Vodič pa zahteva predznanje iz programskega jezika C (osnove, kazalci, I/O, delo z nizi, strukture, delo s pomnilnikom).

Krająa razlaga

Verjetno poznate Windows konfiguracijske datoteke, ki imajo končnice .inf in so podobne temu:

port=3256
n_users=42
read_data=data.dat

To je zelo enostaven zapis nastavitev. Vsebuje namreč dve strani: Leva, ki je kot nekakąen ukaz oz. oznaka, in desna stran, ki označuje vrednost ukaza oz. oznake. V zgornjem primeru je torej:

port - oznaka
3256 - vrednost

Torej:

[oznaka] {ločilo} [vrednost]
* oznaka – njeno ime naj bo podobno spremenljivki in naj bo smiselno
* ločilo - je znak; je meja, ki ločuje oznako od vrednosti; najpogostejąe ločilo je znak =
* vrednost – niz in/ali ątevilo, ki ga bo program uporabil za prilagoditev

začetek

Da se bo program prevedel brez napak, moramo vstaviti naslednje knjiľnice:

#include <stdio.h>
#include <stdlib.h>
#include <string.h>

Naąa rutina bo prebrala nastavitve in razbrala, kaj je ukaz ter kaj je vrednost in seveda program temu ustrezno prilagodila. Program je napisan v C-ju, torej brez new operatorja. Naredil pa bom primer programa, ki iz nastavitvene datoteke razbere, katero datoteko naj prebere in do kam jo mora prebrati. Zavedam se, da bi kodo lahko napisal bolje vendar je potrebno upoątevati dejstvo, da je to le začetek. Programske kode ne bom natančno razlagal, ampak dodal le komentarje. Torej, preberite jih! Napisani so v C++ slogu (osebno se mi zdi bolj estetsko). Priporočam pa, da si ogledate izvorno kodo za ta program, ker koda, ki je predstavljena v tem vodiču, ne vsebuje nepomembnih podrobnosti (za nalaganje nastavitev iz konfiguracijske datoteke). PRI KONFIGURACIJSKI DATOTEKI NAJ BO NA KONCU VEDNO PRAZNA VRSTICA!

Najbolje je najprej napisati definicije vseh tag-ov (oznak), ki se bodo uporabljale v nastavitveni datoteki. V naąem primeru torej:

#define TAG_FILENAME "FileName" /* Ime datoteke, ki jo bomo odprli in prebrali del njene vsebine. */
#define TAG_READ_TO "ReadTo" /* Stevilo bajtov, ki bomo prebrali iz datoteke */

Napiąemo ąe definicije, ki bodo določale maksimalno velikost oznake, vrednosti in vrstice v datoteki.

#define MAX_TAG_LEN 20 /* Maks. velikost oznake. */
#define MAX_VAR_LEN 50 /* Maks. velikost vrednosti. */
#define MAX_LINE_LEN 100 /* Maks. velikost ene vrstice v datoteki. */

To pa zato, da je program bolj prilagodljiv. Napiąemo ąe definicijo privzete nastavitvene datoteke s katere bo program bral podatke:

#define DEFAULT_INIFILE "program_start.ini"

Da bo program malo bolj organiziran, bomo naredili strukturo, ki bo vsebovala vse prebrane vrednosti iz datoteke:

/* Struktura, ki bo vsebovala prebrane informacije
   iz konf. datoteke. */
struct VARS
{

    char *src_file; /* Datoteka, iz katere bo program 
    				   bral besedilo. */

    int read_to;    /* Koliko bajtov bo prebral iz datoteke 
    				   src_file. */

}vars;

Uvod je v bistvu končan. Začenja se jedro, kjer bomo napisali funkcijo, ki prebere vrstico iz konfiguracijske datoteke, funkcijo, ki ločuje oznako od vrednosti in funkcijo, ki bo prebrane podatke uveljavila v programu.

Jedro

Naredimo funkcijo, ki izprazne polje, ki bo vsebovalo začasne podatke. Ker bomo polje večkrat potrebovali, moramo poskrbeti, da bo počiąčeno, preden bo ponovno uporabljeno. Zatorej:

void empty_array()
{
    memset((char *)edited_line[0], '\0', MAX_TAG_LEN);
    memset((char *)edited_line[1], '\0', MAX_VAR_LEN);
}

Branje vrstic

Da bomo lahko kaj razbrali, moramo najprej iz datoteke DEFAULT_INIFILE (privzete konfiguracijske datoteke) prebrati vrstico.

Delovanje bo sledeče: Beremo vsako vrstico posebej, do konca datoteke. Ko preberemo vrstico, jo obdelamo (ločevanje, ...) in nato preberemo naslednjo. Konec vrstice bomo zaznali, ko bomo naleteli na znak \n (nova vrstica) ali ko bomo naleteli na konec datoteke (!feof()).

void read_line(FILE *_stream, char *buffer)
{
    /* Prebrani znak. */
    char znak;
    /* Steje stevilo prebranih znakov. */
    int i = 1;
    /* Ta kazalec bo vseboval prebrano vrstico,
       brez prelomnega znaka. */
    char *temp = NULL;
    /* Pocistimo buffer z znakom '\0'. */
    memset((char *)buffer, '\0', MAX_LINE_LEN);
	 /* Glavna while zanka. */
	 while ((znak != '\n'))
    {
        /* Ce je tragicni konec datoteke. */
        if ((znak = fgetc(_stream)) == EOF)
        {
            (* buffer) = 0;
            break;
        }
        /* Pisemo vsak znak posebej v medpomnilnik. */
        buffer[i - 1] = znak;
        /* Povecamo stevilo prebranih znakov. */
        i++;
    }
    /* Doda null-terminated znak. */
    if (buffer != NULL)
    buffer[i - 2] = '\0';
}

Obdelava vrstice

Naredili smo funkcijo, ki zahteva tok datoteke in vrne prebrano vrstico. Nato vrstici določimo oznako in vrednost. To storimo tako, da iz začetka niza beremo znake, dokler ne naletimo na ločilo (ponavadi je to ločilo znak =). Narediti moramo ąe dodatno polje, ki bo vsebovalo oznako in vrednost, ki jo je iz prebrane vrstice razbrala funkcija read_line(). Zatorej:

char *edited_line[2];

Sedaj pa ąe ta znamenit ločevalni stroj:

void process_line(char *line)

{

    char counter = 0; /* Kazipot za vrstico. */

    char count_var = 0; /* Kazipot za edited_line. */

    char line_size = strlen(line); /* Velikost vrstice(v bajtih)*/
     /* Iscemo oznako. */
    while(line[counter] != '=')
    {
        edited_line[0][counter] = line[counter];
        counter++;
    }
    counter += 1; /* Preskocimo locilni znak. */
    /* Iscemo vrednost. */
    while(line[counter] != '\0')
    {
        edited_line[1][count_var] = line[counter];
        counter++;
        count_var++;
    }
}

Nastavljanje programa

Končali smo s funkcijo, ki poiąče oznako in vrednost ter ju shrani v edited_line[0] in edited_line[1]. Narediti moramo ąe funkcijo, ki bo vpisala prebrane vrednosti v strukturo vars.
Funkcija se imenuje configure_app().

void configure_app()
{
	/* Preverja nize. Lahko naredimo tudi tabelo in se po njej
	   orientiramo. */
    if ((strcmp(edited_line[0], TAG_FILENAME)) == 0) {
        vars.src_file = (char *)malloc((strlen(edited_line[0])));
        strcpy(vars.src_file, edited_line[1]);
	}
    else if ((strcmp(edited_line[0], TAG_READ_TO)) == 0) {
		int temp = atoi(edited_line[1]);
		vars.read_to = temp;
	}
}

Če bi kdaj drugič načrtovali raząiritev oznak, moramo tukaj napisati dodatne pogojne stavke zanj. Tako. Sedaj smo pripravljeni, da napiąemo funkcijo main(), ki bo vso to čudo zdruľila:

int main(int argc, char *argv[])
{
    /* Konfiguracijska datoteka. */
    FILE *setup;
    /* Datoteka, ki bo pozneje prebrana. */
    FILE *msg_file;
    /* Ena vrstica lahko ima maksimalno MAX_LINE_LEN znakov. */
    char *line = (char *) malloc(MAX_LINE_LEN);
    if ((setup = fopen(DEFAULT_INIFILE, "r")) == NULL)
    {
        printf(
        "Napaka pri odpiranju konfiguracijske datoteke \'%s\'!\n",
        DEFAULT_INIFILE
        );
        return(-1);
    }

	/* maks. 20 znakov za oznako. */
    edited_line[0] = (char *)malloc(MAX_TAG_LEN);
	/* maks. 50 znakov za vrednost. */
	edited_line[1] = (char *)malloc(MAX_VAR_LEN);
    /* Zanka, ki bo omogocila branje vrstic in nato se njihovo 
       obdelavo. */
    while (!feof(setup))
    {
        memset((char *)line, '\0', MAX_LINE_LEN);
        read_line(setup, line);
        if ((*line) == 0) /* preberemo vrstico. */
        break;
        empty_array(); /* Spraznimo polje edited_line[]. */
        process_line(line); /* Obdelamo vrstico. */
        /* Nastavi program z nasimi prebranimi nastavitvami. */
        configure_app();
    }
    /* Odpre navedeno datoteko v datoteki DEFAULT_INIFILE. */
    if ((msg_file = fopen(vars.src_file, "r")) == NULL)
    {
        printf("Datoteke \'%s\' ni mogoce odpreti!\n",
        		vars.src_file);
        return(-2);
    }
    /* Ker konfiguracijske datoteke ne potrebujemo vec, jo zapremo. */
    fclose(setup);
    /* vars.read_to ne sme biti veccji od datoteke! */
    for(int i = 1; i <= vars.read_to; i++)
    {
        printf("%c", (fgetc(msg_file)));
    }
    /* Zadnje delo, ki ga opravi program preden se konca. */
    fclose(msg_file);
    /* Pocistimo vse rezervirane prostore. */
    free(edited_line[0]);
    free(edited_line[1]);
    free(line);
    return(0);
}

Zaključek

Pa smo ľe pri zaključku! Za primer ustvarimo datoteko program_start.ini, ki se nahaja v imeniku, kjer je naą program. Vsebuje naj:

FileName=msgtext.txt
ReadTo=30

Datoteka msgtext.txt pa naj vsebuje:

»Naredili smo funkcijo, ki zahteva tok datoteke in vrne prebrano vrstico. Nato vrstici določimo oznako in vrednost. To storimo tako, da iz začetka niza beremo znake, dokler ne naletimo na ločilo (ponavadi je to ločilo znak =). Narediti moramo ąe dodatno polje, ki bo vsebovalo oznako in vrednost, ki jo je iz prebrane vrstice razbrala funkcija read_line(). Zatorej:«

torej odlomek tega vodiča(brez narekovajev). Če program zaľenemo, bo izpisalo naslednje:

Naredili smo funkcijo, ki zaht

Koda v tem vodiču je sploąna, kajti manjka ąe veliko stvari, kot npr. komentarji (po ľelji). Če se boste lotili projekta, ki bo vseboval to ali podobno kodo, morate obvezno ąe napisati funkcijo, ki bo odstranila vse presledke v prebrani vrstici. Kajti, če uporabnik v konfiguracijsko datoteko po nesreči doda presledek vmes ločila (kar je pogosto), ta program oznake ne bo prepoznal ali pa bo prebral napačno vrednost.

Upam, da vam je vodič bil v pomoč. Izvorno kodo lahko poljubno uporabljate.
