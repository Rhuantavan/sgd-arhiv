Živjo,

Rad bi naredil simple editorček za vnašanje vrednosti (podobno kot excel samo bolj preprost)., zato moram najprej narediti razred, ki bo operiral nad podatki oz. celicami (brisanje, dodajanje, sortiranje). Za container
sem si izbral STL map, ki ima za "KEY" tip TCellCoord in za "VALUE" tip
PCellData. Določil sem tudi razred CellSortCriterion, ki mi sortira celice
v map-u in sicer naprej po kolonah(Col) in potem po vrsticah(Row).
Za probo sem napisal spodnji program in deluje vse lepo in prav.

Bi pa prosil za nekaj komentarjev oz. nasvetov v zvezi s tem,
kako vsa stvar funkcionira oz. kako moram napisati, da bo
brisanje, dodajanje , urejanje celic čimbolj hitro.

1. problem:
Kako hitro je oz kako deluje iskanje z metodo find (v funkciji main sem napisal primer iskanja po ključu oz po koordinatah celice), ker se bom moral hitro sklicevati na določeno celico po njenih koordinatah. V deliphiju
sem imel napisano iskanje z bisekcijo in stvar je delala brez problema. Ali
bo najbolje, da sam napišem iskanje ali je find metoda dovolj hitra.

2. problem
Kar se hitrosti tiče je najbolje v container filati pointerje in ne
celih objektov torej jaz dodam v posamezen zapis containerja
cel objekt tipa TCellCoord za KEY in pointer na tip TCellData kot
VALUE. Ali je to sprejemljivo.

3. problem
Ali sem se stvari lotil na pravi način in oz. kaj predlagate vi.

Hvala za odgovore









Koda:

#include <map>
#include <iostream>

using namespace std;


// TCellCoord - koordinate celice
typedef struct {
   int Col;
   int Row;
} TCellCoord;

// TCellData - vrednost celice   
typedef struct {
   char* Value;
} TCellData;

//PCellData
typedef TCellData* PCellData;


// CellSortCriterion
class CellSortCriterion {
  public: 
    // Če je [ (Col1 manjse Col2) ALI ( (Col1 je enako Col2) IN (Row1 manjse Row2 ) ) ]
    bool operator() (const TCellCoord& CellCoord1, const TCellCoord& CellCoord2) const {
        return ( (CellCoord1.Col < CellCoord2.Col) ||
         ( (CellCoord1.Col == CellCoord2.Col) && (CellCoord1.Row < CellCoord2.Row) ) );
    }
};

// TCellsMap
typedef map<TCellCoord, PCellData, CellSortCriterion> TCellsMap;

// fCellCoord
TCellCoord fCellCoord(int Col, int Row)
{
   TCellCoord cc;
   cc.Col = Col;
   cc.Row = Row;
   return cc;
}


// PrintMap
void PrintMap(TCellsMap &CellsMap)
{
   TCellsMap::iterator pos;

   for (pos = CellsMap.begin(); pos != CellsMap.end(); pos++)
   {
      cout << "Col: " << pos->first.Col << " Row: " << pos->first.Row << endl;
   }
}


//Main
int main(int argc, char* argv[])
{
   TCellsMap celice;   // primerek tipa TCellsMap

   // dodam nekaj poskusnih vrednosti
   celice.insert( TCellsMap::value_type(fCellCoord(1, 3), NULL) );
   celice.insert( TCellsMap::value_type(fCellCoord(3, 1), NULL) );
   celice.insert( TCellsMap::value_type(fCellCoord(5, 7), NULL) );
   celice.insert( TCellsMap::value_type(fCellCoord(1, 5), NULL) );
   celice.insert( TCellsMap::value_type(fCellCoord(12, 5), NULL) );
   celice.insert( TCellsMap::value_type(fCellCoord(12, 2), NULL) );
   celice.insert( TCellsMap::value_type(fCellCoord(14, 0), NULL) );
   celice.insert( TCellsMap::value_type(fCellCoord(6, 1), NULL) );
   celice.insert( TCellsMap::value_type(fCellCoord(12, 4), NULL) );
   
   // Izpisem vrednosti
   PrintMap(celice);

   // poskus iskanja
    /*TCellsMap::iterator pos;
   pos = celice.find(fCellCoord(12,5));                   
    if (pos != celice.end()) {
        cout << "yes";
    } else
   {
      cout << "no";
   }*/

   // pocistim celice
   celice.clear();

   return 0;
}

Hja stvar je takšna gre pa takole:

1.) Za vnašanje entryev v tabelo real time aplikacija ni glih pojem. Niti ni važno če vnos traja desetinko sekunde ali pa eno stotinko. Tako da je vseeno samo da dela ( okej 10 sekund je že preveč ali tega verjetno ne boš doživel ).
