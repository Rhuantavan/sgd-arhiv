C++ related:
No, na jokerju se je razvila ena debata kako naresti 2D dinamicno polje (z new).

Kos torte (piece of cake)!








Koda:

float* Medo;
Medo = new float*[16];
for (int i = 0; i < 16; i++) {
Medo[i] = new float[16];
}

for(int n = 0; n<16; n++)
delete[] Medo[n];
delete[] Medo;



No, deluje vsekakor. Tudi za n-dimenzije. Vendar pa mi tele zanke ne zgledajo lepo (niti hitro).

Zato (kot je v praksi) vso stvar stlacis v 1D:









Koda:

float *snake;

snake = new float[16*16];

delete[] snake



Nato pa je prislo vprasanje o vec kot dveh dimenzijah.

Pa me zanima, ce se komu da razmisljat. A sem ga kje pri spodnji kodi polomil? Sem napisal zelo na hitro, tako da napake so vsekakor mozne!









snake na jokerju je napisal:
3D
a = new int[X*Y*Z]

a[(st_stolpca-1)*X*Z+(st_vrstice-1)*Z+globina]

4D
4D si predstavljajte kot vec hisic (ce je S 1, potem imamo eno hiso, ce je 2 imamo dve, itd.)

a = new int[X*Y*Z*H]

a[((st_stolpca-1)*X*Z+(st_vrstice-1)*Z+globina)*st_hise]


5D
5D je podobno kot 4D, le da vse skupaj razsirimo se na mesta (ce je M 1, potem imamo le eno mesto, ce je 2 imamo dve mesti, itd.)

a = new int[X*Y*Z*S*M]

a[(((st_stolpca-1)*X*Z+(st_vrstice-1)*Z+globina)*st_hise)*st_mesta]



itd. itd. razsirjamo nas svet
namesto st_stolpca, st_vrstice, globina,... bi bilo bolje, ce bi dali: 1_dimenzija, 2_dimenzija, 3_dimenzija, n_dimenzija
tako nas ne bi omejevala domisljija, ko bi prisli do st_galaksije

Se ne da nobenmu poglabljat, drugace bi odkrili napako

takole gre:

3D je se prav, 4D in naprej gre pa tkole:

4D
a = new int[X*Y*Z*H]

a[(st_hise-1)*X*Y*Z +(st_stolpca-1)*X*Z+(st_vrstice-1)*Z+globina]


5D
a = new int[X*Y*Z*H*M]

a[(st_mesta-1)*X*Y*Z*H +(st_hise-1)*X*Y*Z +(st_stolpca-1)*X*Z+(st_vrstice-1)*Z+globina]


V splosnem:
a = new int[D1*D2*D3*...*Dn]

a[(dn-1)*D1*D2*...Dn-1 + (dn-1 -1)*D1*D2*...*Dn-2 + (dn-2 -1)*D1*D2*...*Dn-3 +...+ dokler je n vecji od 3, potem pa (d1-1)*D2*D3+(d2-1)*D3+d3]

Tako velike crke (D1, D2, D3,...Dn predstavljajo zacetno velikost polja sirino, visino, globino,...) ,male crke d1, d2,...,dn pa mesto do katerega zelimo dostopati (d1 == X, d2 == Y,...).

int x,y;
x=30;y=30;

int **a = new *int(x); //začneš s pointerjem na polje pointerjev tipa int.
for(int i = 0; i < y; i++;) a[i] = new int(y); //pointerje potem nastavmo vsakega na en array int-ov
