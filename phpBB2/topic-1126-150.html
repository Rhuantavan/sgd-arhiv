Hja tam so planeti nametani po celem sončnem sistemu in se ne premikajo. Tudi vrtenje planetov ni animirano.

Animirano je samo premik vesoljske ladjice, kar pri meni spet odpade, saj za začetek. Drgač pa si lahko ziher kje potegneš original dol, če ne pa jaz dam na voljo. Imam patch-ano do deluxe verzije (zadnje).

Drgač pa zadeva bo taka: v igri imaš tri surovine: kovina, hrana (biologic material) in radioactivity (energija). Na vsakem planetu zbiraš te tri prvine, vendar ne moreš na vsakem planetu dobiti enako. Na enih več, na drugih manj. Recimo na tistih planetih, ki so oblj biološko bogati, ne moreš dobiti veliko radioaktivnosti iz njih. Kovina pa se generira kot naključno število med 0 in 100 (polno vrednostjo). Na vsakem planetu, boš lahko sicer gradil poslopja, tovarne itd. s katerimi boš lahko izboljšal doprinos prvin. (+10 metal na skupen račun planeta). Poleg tega, bodo zvezde v osončju proizvajale dodaten vir energije, ki ga boš lahko pobiral z posebnimi ladjicami.

Metal boš rabil za izdelavo novih ladjic, biološki material bo za futrat folk in delavce (ki bodo delai stavbe, ladjice in raziskovali), energijo pa boš nucal za laufanje planeta, proizvodnje in za pogon ladjic. Prav tak bo treba futrati posadke na ladjicah. Zaenkrat je tole moj cilj, potem pa bomo še izdelali combat in ostalo.

glede *.au pa pahko uporabiš kaj takega: (stem da kodo predelaš po svojih potrebah)

To zna predvajat *.wav in *.au









Koda:
import java.io.File;

import javax.sound.sampled.AudioFormat;
import javax.sound.sampled.AudioInputStream;
import javax.sound.sampled.AudioSystem;
import javax.sound.sampled.DataLine;
import javax.sound.sampled.SourceDataLine;

public class Play
{
/**
* Play a *.wav or *.au file
*
* @param args args[0] on command line is name of file to play
*/
public static void main ( String[] args )
{
try
{
AudioInputStream ais =
AudioSystem.getAudioInputStream ( new File ( args[0] ) );
AudioFormat af = ais.getFormat();
DataLine.Info info = new
DataLine.Info ( SourceDataLine.class, af );

if ( ! AudioSystem.isLineSupported ( info ) )
{
System.out.println( "unsupported line" );
System.exit( 0 );
}

int frameRate = (int)af.getFrameRate();
System.out.println( "Frame Rate: " + frameRate );
int frameSize = af.getFrameSize();
System.out.println( "Frame Size: " + frameSize );
int bufSize = frameRate * frameSize / 10;
System.out.println( "Buffer Size: " + bufSize );

SourceDataLine line = (SourceDataLine)
AudioSystem.getLine( info );
line.open( af, bufSize );
line.start();

byte[] data = new byte[bufSize];
int bytesRead;

while ( ( bytesRead = ais.read( data, 0, data.length ) ) != -1 )
line.write( data, 0, bytesRead );

line.drain();
line.stop();
line.close();
}
catch ( Exception e )
{
System.out.println( e.toString() );
}
System.exit( 0 );
}
}
