Živjo,

Tile char*-i v c++ so od hudiča
Rabim proceduro, ki bo prekopirala iz ene char*
spremenljivke svojo vsebino v drugo char vsebino.

Da še moj spodnji poskus malo opišem.
Če je dest NULL in src različno od NULL potem
kreiram nov dest in poskušam prekopirati vsebino
src-ja v dest. Če je src NULL bi moral biti tudi dest NULL, čeprav to še ni napisano.
Težave pa so, ker mora imeti dest zasedati dovolj prostora za vsebino src-ja.
V glavnem moj cilj je da mora imeti dest isto vsebino kot src in zasedati enako
prostora, kot src, če pa je src NULL moram uničiti dest in ga postaviti na NULL.
Ker imam bolj malo iskušenj s chari, bi vas prosil če mi kakšen profi tole malo
razjasni,predvsem kako bi lahko zmanjšal oz povečal glede na src velikost dest,
da bi lahko brez napake kopiral znake.


Hvala za odgovore

Anze









Koda:



// arPCharAssign
void arPCharAssign(pchar &dest, const pchar src)
{
// Če je dest NULL in src različno od NULL kreiram nov dest
if ( (dest == NULL) && (notnull(src)) )
{
dest = new char[strlen(src) + 1];
}

if ( (notnull(dest)) && (notnull(src)) )
{
strcpy(dest, src);
}
}


// Pa še to kar je v funkciji uporabljeno

// notnull (Preveri ee ni podan element NULL)
template <class T>
inline bool notnull(T & x)
{
return (x != NULL);
}

// pchar
typedef char* pchar;

// zaparr (funkcija za sprostitev dinamienih arrayev)
template <class T>
inline void zaparr(T & x)
{
{assert(x != NULL);}
delete [] x;
x = NULL;
}

Koda:



// arPCharAssign
void arPCharAssign(pchar &dest, const pchar src)
{
// Če je dest NULL in src različno od NULL kreiram nov dest
if ( (dest == NULL) && (notnull(src)) )
{
dest = new char[strlen(src) + 1];
}

if ( (notnull(dest)) && (notnull(src)) )
{
delete dest;
dest = new char[strlen(src) + 1];
strcpy(dest, src);
}
}

char *ime;
equals:
var ime : PCHAR;
ali
var ime : ^char; ali byte;

C++ sicer res ima STL knjižice za uporabo stringov:
#include <string>
using namespace std;

string ime("Ales");
string priimek("neznan");
string skupaj = ime + piimek;

ali dobro, to uporablja template in vseskupaj je dokaj kompleksno za dojet, sploh če se seznanjaš s C/C++.
Zatorej nekaj nasvetov:

za zacetek raje kot:

char *pbuff = new buff[100];

uporabljaj:

char buff[100];

Vse funkcije se bodo do obeh spremenljivk obnašale popolnoma isto, le manj memory leakov boš povzročal ko se boš učil. C jevi char "stringi" so 0 terminated namesto pascalovih, npr:

C style:
ALES\0 ( binarno ord('a') ord('l') ord('e') ord('s') 0 )

Pascal style:
4ALES (4=length pol pa a l e s )

Tu je prva razlika. Zatorej ce hoces postavit ime v buffer das:

strcpy(buff,"ales"); in prekopira ales v buff. isto gre za:
strcpy(pbuff,"ales"); nobenih predpon.

ce bi rad primerjal string ( z strng lahko daš a != b ) pri c style pa daš:

if ( !strcmp(stra, strb) ) cout << "Enaka sta";
