Evo bom kar odprl novo temo za vse tiste (kolikor nas pač je), ki se ukvarjamo z FLjem in imamo kaj za povedat, povprašat, itd.

Sam trenutno delam eno Flash zadevco in sem nekako naletel na ...recimo problem.
Sam zaenkrat grafiko v igri uporabljam izključno preko [embed] ukaza, primer:

[Embed(source="../slikca.png")] private var slikca:Class;

ki jo potem pozneje priredim objektu BitmapData razreda. zadeva načeloma ni napačna, dokler se ne pojavi potreba po recimo animaciji, ki bi jo še dodatno rešil z uporabo sheetov - več frejmov animacije v enem fajlu. Sedaj bi rad nekako najlažje recimo vstavil sheet in potem preko BitmapData razreda dobil točno določen frame v fajlu in uporabil za trenutno sličico objekta v igri.

Zadeve trenutno ni potrebno nič kodirati v samem game fajlu, imam namreč to ločeno po objektih v igri - recimo enemy ima embedane svoje grafike in tam samo menjujem bitmapdata informacijo o trenutnem sprajtu, zato bi nekako še naprej ohranil tako strukturo če se da - zadeve ločene tako, da grafika za risanje enemija pripada datoteki enemy.as. Recimo.

Evo po par dneh tuhtanja, branja Grandyevega bloga in spraševanja po forumih je problem rešen (primer na 96x32 (š x v) sprite sheetu 3 kvadratkov dimenzije 32x32):









Koda:
package
{
import flash.display.Bitmap;
import flash.display.BitmapData;
import flash.geom.Rectangle; //rectangle za kopiranje sheeta
import flash.events.Event; //import za enter frame event (loop v igri)

public class kocka extends Bitmap
{
[Embed(source = '../lib/test.PNG')] private static var sourceImg:Class; //source datoteka - sprite sheet npr

private static var sourceImage:BitmapData = (new sourceImg).bitmapData; //ustvari bitmapdata sourceImg, izvor je sourceImg
private static var frame:Bitmap;
private var numFrames:int = Math.floor(sourceImage.width/32); //število framov dobimo, tako, da delimo širino slike z 32 in zaobkrožimo navzdol (v tem primeru je sheet horizontalen!!!)
private var framesArray:Array = new Array(); //array za shranjevanje frejmov
private var currentFrame:int = 0; //trenuten frame (za loop)

public function kocka()
{
for (var i:int = 0; i < numFrames; i++)
{
var frame:BitmapData = new BitmapData(32,32);
var frameRect:Rectangle = new Rectangle(i*32,0,32,32);

frame.copyPixels(sourceImage, frameRect, frame.rect.topLeft); //na trenuten frame kopiramo pixle iz sourceImage bitmapa, kvadratek (dimenzije zgoraj), center frejma
framesArray.push(frame); //potisnemo trenutni frame v tabelo
}

addEventListener(Event.ENTER_FRAME, enterFrame); //dodamo listener za loop v igri
}

public function enterFrame(event:Event):void
{
bitmapData = framesArray[currentFrame]; //za prikaz izberemo trenutni frame

if (currentFrame < 2) //če je frame manjši od 2 (sam sem imel 3 frejme, prvi je v tabeli označen z 0)
currentFrame += 1; //povečamo counter
else
currentFrame = 0; //začnemo znova
}
}
}



zadeva dela, v oči bode le to, da je v tem primeru loop neverjetno hiter (dejanski fps igre). problem se komot, da rešiti z vpeljavo kakšnega countdowna, ki sliko menja, ko je števec na nič, etc.

woho, problem miljarde datotek je rešen, sedaj pa na naslednje problemčke ^^
