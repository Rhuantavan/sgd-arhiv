Ravno sem rabu to zadevo nekaj, pa sem si prepisal v VB.NET iz Matlaba funkcijo, ki sem jo enkrat za domačo pri numerični linearni algebri naredu.
Za vse, ki ne veste kaj to je: recimo, da je sistem enačb tak:

A(0,0)*x(0) + A(0,1)*x(1) + ... + A(0,n-1)*x(n-1) = b(0)
...
A(n-1,0)*x(0) + A(n-1,1)*x(1) + ... + A(n-1,n-1)*x(n-1) = b(n-1)

Poznamo A in b, iščemo pa x. To, da je sistem tridiagonalen pa pomeni, da so v A samo elementi A(i,i), A(i,i-1) in A(i,i+1) različni od nič.

Nism nič pisal preveč kako dela, za tiste ki poznate zadevo je stvar narejena z LU razcepom s pivotiranjem (optimizirano za tridiagonalni sistem)









Koda:
Private Function GaussTriDiag(ByVal A(,) As Single, ByVal b() As Single) As Single()
'VB-zation from my matlab code
Dim last As Integer = 0
Dim l As Integer
Dim n As Integer = A.GetLength(0)
Dim d(n - 2) As Integer 'lokacije pivotiranja
Dim i, j As Integer
Dim x(n - 1) As Single 'rezultat
Dim tmp As Single

For i = 0 To n - 2
l = 1 'ni pivotiranja
If Abs(A(i + 1, i)) > Abs(A(i, i)) Then
l = 2 'pivotiramo
If i + l >= n - 1 Then
l = 1
End If
d(i) = l
For j = 0 To n - 1
tmp = A(i, j)
A(i, j) = A(i + 1, j)
A(i + 1, j) = tmp
Next
tmp = b(i)
b(i) = b(i + 1)
b(i + 1) = tmp
End If
A(i + 1, i) /= A(i, i)
A(i + 1, i + 1) = A(i + 1, i + 1) - A(i + 1, i) * A(i, i + 1)
If l = 2 Then A(i + 1, i + 2) = A(i + 1, i + 2) - A(i + 1, i) * A(i, i + 2)

If i > 0 AndAlso l = 1 Then
x(i) = b(i)
For j = last To i - 1
x(i) -= A(i, j) * x(j)
Next
last = i
Else
x(i) = b(i)
End If
Next
x(n - 1) = b(n - 1)
For j = last To n - 2
x(n - 1) -= A(n - 1, j) * x(j)
Next
x(n - 1) /= A(n - 1, n - 1)
For i = n - 2 To 0 Step -1
For j = i + 1 To i + d(i)
x(i) -= A(i, j) * x(j)
Next
x(i) /= A(i, i)
Next
Return x
End Function

OK, zgleda da sem bil preveč optimist. No pa še poenostavljena varianta, ki bo sicer razložila kaj to pomeni ampak v tem primeru stvar ni uporabna (se ne splača tolk komplicirat)

Recim da imaš sistem enačb:

3x+5y+0z=6
2x+7y+2z=9
0x+8y+4z=1

Treba je ugotoviti kakšno vrednost morajo imeti x,y in z da bodo vse enačbe izpolnjene. Sistem je tridiagonalen, ker so koeficienti različni od nič le na diagonali(zgoraj levo->spodaj desno) in ob diagonali. Seveda tega ne boš reševal z zgornjo metodo. Če pa imaš 100 in več spremenljivk (ali pa tudi če jih je 10) se pa že splača.

Aha, pa splača se omenit, da dobi zgornja funkcija predstavljen sistem v matrični obliki: Ax=b. Poznamo matriko A (koeficienti) in b (desne strani enačb), iščemo pa spremenljivke x(0) do x(n-1).
