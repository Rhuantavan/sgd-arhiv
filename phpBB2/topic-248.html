Še nisi slišal za SQL ?
SQL sam je neke vrste programski jezik (structured query language) in se uporablja v povezavi z bazo, da iz nje dobiš poatke ali pa le te vneseš/zbrišeš.

SQL strežnik pa je strežnik podobno kot je strežnik apache ali IIS samo da SQL strežnik ne "servira" spletnih strani ampak podatke (iz baze).
Obstaja seveda več vrst SQL strežnikov, nekateri so zastonj nekateri niso zastonj.
Recimo : mySQL, mSQL, MSSQL, Oracle, postreSQL, ...

Razlikujejo se po funkcijah, hitrosti, ...
