Koda:
Dim p2 As New clsProduct



Preden deserializiraš ni potrebe ustvariti nov objekt. Pri deserializaciji se bo objekt tako ali tako ustvaril.

Pri imenih spremenljivk se pa poskušaj izognit poimenovanju, ki vsebuje kot predpono tip spremenljivke. Malo si preberi design guidelines, ki jih najdeš v MSDN. Mogoče si tudi poglej FxCop.

No zdaj pa odgovor. Sicer si to že videl se mi zdi, pa ne bo škodilo če še kdo drug vidi.

    <XmlIgnore()> _
    Public Shared Serializer As New XmlSerializer(GetType(GameSettings))

    Public Shared Function Load(ByVal fileName As String) As GameSettings
        Dim fs As New FileStream(fileName, FileMode.Open)
        Dim ret As GameSettings = DirectCast(Serializer.Deserialize(fs), GameSettings)
        fs.Close()
        Return ret
    End Function

    Public Sub Save(ByVal fileName As String)
        Dim fs As New FileStream(fileName, FileMode.Create)
        Serializer.Serialize(fs, Me)
        fs.Close()
    End Sub
End Class
