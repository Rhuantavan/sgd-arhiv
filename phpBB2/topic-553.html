Naravnost bo tu težko povedat karkoli. Problem je v tem da je AI zelo široko področje. Če te zanimajo robotki potem boš verjetno kaj hitro naletel na problem path findinga, vsaj če gre za mobilne robotke. Tukaj je najbolj osnoven (pa tudi kar učinkovit) pristop z algoritmom A*. Seveda je še veliko drugih bolj specializiranih variant, vendar glede na to da si začetnik je dobro da začneš na začetku.

Kako zgleda AI? Dosti je standardnih pristopov, kako se lotiti standardnih problemov umetne inteligence. Vendar pa se izkaže da je v konkretnih primerih implementacije potrebno dodati zraven kar veliko domišlije in iznajdljivosti, da dosežeš željen rezultat.

Koda:

const int      STATE_IDLE              = 0;
const int      STATE_ATTACK          = 1;

class Objekt
{
public:
                  Objekt();
    int          mdState;
    void        Update();
};

Objekt::Objekt()
{
      mdState = 0;
}

void Objekt::Update()
{
        if(mdState == STATE_IDLE)
        {
                  // poglej naokoli
                  if( TargetFound() )
                        mdState = STATE_ATTACK;
        }
        if(mdState == STATE_ATTACK)
      {
              // pošči tarčo
              // pojdi proti tarči
              // streljal
                if(TargetIsDead())
                        mdState = STATE_IDLE;
      }
}
