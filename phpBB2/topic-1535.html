ok, tvoj trikotnik je definiran z tremi točkami: A, B, C. točka je v morem primeru recimo:









Koda:

struct point
{
float x,y,z;
};



point A,B,C;

1. izračunaš vektor U, ki je definiran kot B-A. torej tako:

U = (B.x-A.x,B.y-A.y,B.z-A.z)

2. izračunaš vektor V, ki je definiran kot C-A in se izračuna podobno kot zgoraj

3. normalni vektor trikotnika je enak vektorskemu produktu vektorjev U in V. ta produkt je definiran kot:

UxV = ( U.y*V.z-U.z*V.y, U.z*V.x-U.x*V.z, U.x*V.y-U.y*V.x )

torej so tvoji x,y in z:

x = U.y*V.z-U.z*V.y
y = U.z*V.x-U.x*V.z
z = U.x*V.y-U.y*V.x
