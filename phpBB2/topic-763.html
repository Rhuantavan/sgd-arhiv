Soldat Bot Generator

Tistemu ki se ne svita kaj bi bilo to naj si ogleda igro Soldat (www.soldat.pl)

No najprej sem SBG sprogramiral v C++ (nisem naredil v C#, ker ga nisem zadosti znal). Program je imel nekaj problemov in ni še znal določati barv botom.

No danes sem se odločil in naredil to v C#, program deluje dosti boljše in je opazno manjši (v C++ je bil 311kb (100kb zazipan z readme), zaradi mojega neumnega programiranja ) velik je le 24kb (4kb zazipan z readme). V bljižni prihodnosti nameravam narediti še Random Soldat Bot Generator, ki bo bote generiral naključno.

PS: Če hočeste source mi povejte
PSS: Da ne bo kdo kot CWIZO mislil da je to programiranje AI, to je le dajanje podatkov o botu npr. natančnost, barve, ipd.

Soldat Language Maker

No, naredil sem drugo orodje za soldata.
Tukaj lahko igro prevedeste v svoj jezik.
Resda da zato potrebujete kar nekaj časa,
prevesti je namreč treba okrog 620 vrstic.
Kakšne vrstice so po samo eno besedo.
Tudi ta program je velik le 4kb (zazipan z readme).
Tako kot za Soldat Bot Generator tudi za tega potrebujete .NET framework.
Source je zelo kratek zato sem se odločil da ga kar dam sem.








Koda:
using System.IO;

namespace Soldat_Language_Maker
{
   class Class1
   {
      [STAThread]
      static void Main(string[] args)
      {
         string filename;
         string input;
         string output;
         Console.WriteLine("WELCOME TO SOLDAT LANGUAGE MAKER\n\nI hope that you read readme first\nHere will be displaying text in english, \nyou should change text to lenguge that you want\n\n First type here a language that you want to do:");
         input = Console.ReadLine();
         filename= input + ".txt";
         StreamWriter write = new StreamWriter(filename);
         StreamReader read = new StreamReader("english.txt");
         for(int c=0;c<622;c++)
         {
            output = read.ReadLine();
            Console.Write(output + " -> ");
            input = Console.ReadLine();
            write.WriteLine(input);            
         }
         write.Close();
         read.Close();
         Console.WriteLine("\n\n                                        Thank For using this program by TbC");
         Console.WriteLine("                  View web page of the clan: http://www.tbc-soldat.cjb.net");
         Console.WriteLine("                  View web page of the author: http://ArYeS.slogamedev.net");
         System.Threading.Thread.Sleep(3500);
      }
   }
}
