Pozdravljeni!

Kdor koli je že vprašal za podporo GMAX formatu, je na discreetovi spletni strani licence agreement. Opisano je, da je namen GMAXa, da razvijalci iger ne rabijo pisat editorjev za svoje aplikacije/igre ampak si sposodijo user interface in zmogljivosti 3DS MAXa (te so okleščene do te mere da ostanejo še samo koristne stvari za igre). Štos je v tem, da ti torej najameš zastonj editor, poanta pa je v TVOJEM LASTNEM pluginu.

Torej je tu vprašanje drugačno: Kako napisati plugin za GMAX ?

Potrebuje se SDK, katerega pa je treba mastno plačat (mogoče je kje na KAZAA). Licenca potem komitenta upravičuje da uporablja GMAX za komercialne namene, torej kot editor, kjer go generirano 3D okolje za igro, ki bo prinesla denar samo avtorju.

Več kot očitno je, da brez lastnega formata, ali pa kakšnega že obstoječega ne bo šlo. Treba bo napisati exporter plugin za tebi najbolj primerne informacije. Vertexi, Faces, Normale, Smoothing Groups, UV, Materiali in seveda Bones (ima GMAX sploh Character Studio?). Če ne bo šlo drugače uporabite kar nastavitve od Quake 3 - MD3 (nima skeleta), tega lahko convertaš kjer koli MilkShape ali kaj drugega.

Btw.: Ali GMAX dopušča scripting? Če ga, potem ni problema napisat scripte za export (hehe, ampak dvomim da so pri discreetu tako brezbrižni). Iz 3DS Maxa je čisto preprosto exportat geometrijo preko scripte v poljuben format.

Ce se boste lotil pisat svoj exporter vam morda ta koda utegne pomagat zacet:








Koda:


   if objects.count <= 0 then
      (-- nothing to save
      messagebox "No objects to export!"
   ) else (
      -- save to .x file
      output_name = getSaveFileName caption:"Artificial X File" types:"DirectX model (*.x)|*.x|All Files (*.*)|*.*|"
      if output_name != undefined then
         (
         output_file = createfile output_name
      
      ----------
      --HEADER--
      ----------
      
         format "xof 0302txt 0032\n\n" to:output_file   

         format "// ARTIFICIAL X FILE - exported from 3ds max with\n" to:output_file
         format "// Artificial X File Exporter (for shadow models), created by Matt for 3D-Level\n" to:output_file
         format "// www.3dlevel.com\n\n// TEMPLATES" to:output_file
      

      -----------
      --OBJECTS--
      -----------
      
         format "\n// MESHES\n" to:output_file
         
         for o in geometry do (
                  
            -- export all geometry but bones
            if classof o != bonegeometry then (
            
               if o.modifiers.count > 0 then (
                  --remove the skin modifier and colapse
                  o2 = copy o
                  for a = 1 to o2.modifiers.count do (
                     if iskindof o2.modifiers[a] skin then (
                        deletemodifier o2 a
                     )
                  )
                  
                  converttomesh o2
                  mymesh = snapshotasmesh o2
                  delete o2
                  
               ) else (               
                  mymesh = snapshotasmesh o
               )
               
               if isvalidnode o then (
                  
                  format "\n" to:output_file
                  
                  --mesh start
                  format "\n      Mesh % {" o.name to:output_file
                  
                  --mesh vertices
                  format "\n         %;" mymesh.numverts to:output_file
                  for a = 1 to mymesh.numverts do (
                     vert = getvert mymesh a
                     format "\n         %;%;%;" vert.x vert.z vert.y to:output_file
                     if (a == mymesh.numverts) then (format ";\n" to:output_file) else (format "," to:output_file)
                  )
                  
                  --faces
                  format "\n         %;" mymesh.numfaces to:output_file
                  for a = 1 to mymesh.numfaces do (
                     face = getface mymesh a
                     format "\n         3;%,%,%;" ((face.x-1) as integer) ((face.z-1) as integer) ((face.y-1) as integer) to:output_file
                     if (a == mymesh.numfaces) then (format ";\n" to:output_file) else (format "," to:output_file)
                  )
            
                  format "\n      }" to:output_file
               )
            )
         
         )-- next
            
            
         close output_file
         messagebox "Export Done!"
      
      )-- end if
   )-- end if
