void vprasaj(int integer);

extern c ponavadi u porabljas zgolj in samo za tvoje metode. Ce-le te uporabljajo tretje metode, morajo tuje metode zagotoviti, ce mecejo exceptione ali ne. Recimo lep primer je "new" operator. Odvisno od nastavitev in paketa lahko new tudi vrze izjemo.

Eni delajo tako (bolj C style, dasiravno uporabljamo new):
CTexture* pTexture = new CTexture("test.tga");
if( pTexture == NULL ) return E_OUTOFMEMORY;

lahko pa tudi tako (C++):
try
{
CTexture* pTexture = new CTexture("test.tga");
}
catch(...)
{
return E_OUTOFMEMORY;
}

Oba primera ne gresta. Ali vrne NULL ali pa exception. Vse je odvisno od nastavitev ne. Kako pa izgleda, ce je zgornja funkcija pod extern C? Hm, to pa nebi vedel. Vem pa, da v 2005 so exceptioni po defaultu ENABLANi, tudi ce jih ne uporabljate. V slednjem primeru je bolje da jih disejblas.
