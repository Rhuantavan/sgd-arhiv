Ce se ne motim, mamo v Xublu not Bison (http://www.gnu.org/software/bison/), ki nam generira parser in lexer za XublScript, ki ma oklesceno C++ sintakso. Ni pa tok simple za uporabljat, ker mors definitrat cel rule set. Mogoce se kje da najt tak rule set za C++ ze narejen.

Poglej se tole stran:
http://catalog.compilertools.net/lexparse.html

Drugace pa tko, ce rabis samo imena, je pac brute force. Gres byte za byte skos:

1. Isces whitespace znake (space, tab...), zapomnes index
2. Isces '(' od tam naprej. Ce najdes prej whitespace gres na 1. Ce najdes zapomnes index
3. Isces ')' od pozicije 2 naprej. Moras ga najt pred koncem, ce ne je koda invalid.
4. Isces '{' od pozicije 3 naprej. Ce ga najdes je beseda, ki je med indexom iz korakov 1 in 2 ime funkcije

Iz http://en.wikipedia.org/wiki/Parser:

A parser is a computer program or a component of a program that analyses the grammatical structure of an input, with respect to a given formal grammar, a process known as parsing. Typically, a parser transforms some input text into a data structure that can be processed easily, e.g. for semantic checking, code generation or simply to ease the further understanding of the input. Such a data structure usually captures the implied hierarchy of the input and forms a tree or even a graph.
