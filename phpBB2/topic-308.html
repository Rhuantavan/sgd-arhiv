Ker maš relativno lahko preverjanje trkov predvidevam, da preverjaš trke med preprostimi objekti (ravnimi ploskvami).
Način podoben spodnjemu (no ja, v praksi precej bolj zakompliciran) je uporabljala CubeMania za preverjanje trkov kock z ostalimi objekti (npr. zidovi). Deluje skupaj z inputom in opisno izgleda nekako takole:









Koda:
// premikanje objekta za n enot (n je jasno lahko vedno različen)
if (tipka_levo) { objekt.x -= n; }
if (tipka_desno) { objekt.x += n; }
if (tipka_dol) { objekt.y -= n; }
if (tipka_gor) { objekt.y += n; }

// preverjanje trka objekta z leve strani z drugim objektom, imenujmo ga abc
if (tipka_desno == pritisnjena && objekt.x >= abc.x)
{
objekt.x = fiksna_pozicija1; // preprečiš premikanje v stični objekt
}

/* če ne veš kaj mislim: npr. premikaš objekt v desno (povečuješ x), nakar naletiš na objekt in pride do trka: ker premikaš v desno, trčiš v objekt z leve strani (gledano iz stališča objekta, v katerega si trčil) in zato onemogočiš nadalnje premikanje v pozitivno x smer (torej v levi del objekta, s katerim si trčil) - naprej gre podobno
*/

// preverjanje trka z desne strani
if (tipka_levo == pritisnjena && objekt.x <= abc.x)
{
objekt.x = fiksna_pozicija2;
}

// preverjanje trka od spodaj
if (tipka_gor == pritisnjena && objekt.y >= abc.y)
{
objekt.y = fiksna_pozicija3;
}

// preverjanje trka od zgoraj
if (tipka_dol == pritisnjena && objekt.y <= abc.y)
{
objekt.y = fiksna_pozicija4;
}



Pri tem pazi, kaj dejansko predstavlja objekt.x/y oz. abc.y/z - če je to npr. center objekta (če rišeš iz centra na vsako stran), potem moraš prišteti oz. odšteti ustrezno število vsaki koordinati, sicer se bo objekt ustavil npr. na sredini drugega. Npr. če imaš kvadrat 1x1 in rišeš iz 0 (center) proti 0.5 in -0.5 za vsako oglišče, narediš npr.:









Koda:
// preverjanje trka z desne strani
if (tipka_levo == pritisnjena && objekt.x - 0.5 <= abc.x + 0.5)
{
objekt.x = fiksna_pozicija;
}



S tem dosežeš, da se trk zgodi, ko se stikata stični ploskvi oz. robova objektov.

Seveda kodo ustrezno priredi oz. izboljšaj, tu je samo osnovni princip. Recimo težava, ki je bila pri CubeManii je bila, da je bil posamezen kos zidu predstavljen kot kocka (cel zid skupaj pa več kock ena ob drugi), zaradi česar se lahko pojavijo hude težave (ki sem jih sicer uspešno rešil ). Tako da tole je res samo čista osnova, ki za splošno rabo ni najboljša.
