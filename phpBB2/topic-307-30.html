Na točno tak način, kot si ga opisal. Z različnimi plastemi.

takoj nad bazo je prva plast, Data Access Layer (DAL), ki skrbi več ali manj le za dostopanja do baze (izberi to, posodobi to, briši ono, precej ena na ena z bazo).
Nad tem je Busines Layer (BL), ki sinhronizira dostopanje prek DAL do baze, skrbi za varnost (ali imaš pravice, da brskaš po bazi ipd.),...
Nad BL pa potem leži Presentation Layer (user interface komponente ipd.).

Ena kul slikca le-tega:

1, 2: Presentation Layer
3, 4, 6, 8: Business Layer
5, 7: Data Access Layer
9: Varnost, exception handling, komunikacija med servisi, aplikacijami,... (večina tega je uporabna v večjih aplikacijah, vendar pa struktura drži tudi za manjše).


Zelo dobro branje na to temo, pa bi znal biti naslednji članek (malce advanced, a sigurno boš našel kaj koristnega):
Application Architecture for .NET: Designing Applications and Services

OK, zdaj sem preprican, da to ni mogoce

Tko da bo treba datasete ponovno napolniti s podatki (tokrat v preurejenem vrstnem redu stolpcev).

Seveda pa ce te podatke rabis prikazati v kaksni kontroli, se da morda tam prebrkljat kaksen stolpec ali kaj podobnega. ListView kontrola se mi v Detail pogledu zdi zelo primirna izbira. Seveda pa se bos s sortiranjem stolpcev mogel pomujati na roke.

Exampel:








Koda:

DataSet data = new DataSet();
DataTable table = new DataTable("test");
table.Columns.Add("prvi");
table.Columns.Add("drugi");
table.Columns.Add("tretji");
DataRow newrow = table.NewRow();
newrow[0] = "1";
newrow[1] = "2";
newrow[2] = "3";
table.Rows.Add(newrow);
newrow = table.NewRow();
newrow[0] = "11";
newrow[1] = "22";
newrow[2] = "33";
table.Rows.Add(newrow);
data.Tables.Add(table);

this.dataGridView1.DataSource = data.Tables[0] ;
// stolpci v zaporedju: tretji | prvi | drugi (2,0,1)
this.listView1.Columns.Add(data.Tables[0].Columns[2].ToString());
this.listView1.Columns.Add(data.Tables[0].Columns[0].ToString());
this.listView1.Columns.Add(data.Tables[0].Columns[1].ToString());
foreach(DataRow row in data.Tables[0].Rows)
{
// uporabimo isto zaporedje kot zgoraj (2,0,1)
ListViewItem item = new ListViewItem(row[2].ToString());
item.SubItems.Add(row[0].ToString());
item.SubItems.Add(row[1].ToString());

this.listView1.Items.Add(item);
}





Če pa podatke dobiš s kakšnim queryjem ali po kakšni podobno napredni metodi (ne "na roke"), pa je najlažje, da kar v queryju premečes stolpce in si olajšaš delo.
