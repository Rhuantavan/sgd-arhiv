Če prav razumem se ti zaradi uporabe delta tima podre collision detection sistem (statično zaznavanje trkov ne deluje več). Groba metoda je taka, da pač vzameš prejšnjo pozicijo objekta in novo pozicijo objekta, greš čez vse točke in potegneš vektor od stare pozicije točke do nove. Potem pa uporabiš ta vektor kot vhod v postopek za zaznavanje trkov. Verjetno boš moral za to tudi prilagoditi sistem (spisati funkcijo za zaznavanje presečišča med vektorjem in mnogkotonikom, itd ... - dobra referenca za te metode je tole http://www.realtimerendering.com/intersections.html)


Če pa hočeš kaj bolj naprednega pa imaš potem metode ločevanja osi: http://www.geometrictools.com/Documenta ... ngAxes.pdf

Ta CD problem lahko rešiš na dva načina:
1. določiš maximalen dopusten dt; če je dt prevelik, ga razdeliš na manjše:








Koda:

lastTime := SDL_GetTicks()

while appAlive
currentTime := SDL_GetTicks()
dt := currentTime - lastTime
lastTime := currentTime

while dt > MAX_DT
dt := dt - MAX_DT
update( MAX_DT )
update( dt )


2. narediš fixen timestep, ki po potrebi izpušča framee, če prepočasi dela








Koda:

beginTime := SDL_GetTicks()

while appAlive
game.update( DT )
// če je dovolj časa, renderiraj
timeSpent := SDL_GetTicks() - beginTime
if timeSpent < DT
render.update( DT )
// če je še vedno preveč časa, čakaj
timeSpent := SDL_GetTicks() - beginTime
if timeSpent < DT
sleep( DT - timeSpent )

beginTime := beginTime + DT
