Hm, cudno! Najprej, kaj je treba vedet, da DirectX SDK ni isto kot DirectX za ki si ga potegnes za igrice. Nujno moras biti preprican, da si res posnel DX November 2007 SDK, ki zasede najmanj 400MB. Ce je to vse ok, potrem normalno instaliras. Datoteka, ki jo isces bi si po default instalaciji morala nahajati v:

C:\Program Files\Microsoft DirectX SDK (November 2007)\Include

Ce tega direktorija sploh nimas, potem nimas SDKja ampak najbrz cisto navaden DirectX. Ok. Druga stvar, treba je v vistual studio nastavit dve stvari:

Project / Directories / Include :
C:\Program Files\Microsoft DirectX SDK (November 2007)\Include

In pa:
Project / Directories / Library:
C:\Program Files\Microsoft DirectX SDK (November 2007)\Lib\x86

Pozor! Pri vsakem uporabi "puscico" gor, tako da bosta oba na prvem mestu, tako v Include kot v Library. Potem bi moralo delati.

Ce teh direktorijev nimas, potem imas narobe instalacijo SDKja.
Pravi link je tukajle:

http://www.microsoft.com/downloads/deta ... laylang=en
