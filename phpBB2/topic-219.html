Napsy: ja, lahko prodajas programe

Dj: Managed C++ uporablja .NET platformo, torej iste knjiznjice kot vsi .NET jeziki (VB.NET, C#, J#, ...), zatorej managed C++ programi tecejo samo v okoljih z .NET ogrodjem. In, da, prenosljiv je popolnoma enako kot C#. Vsi programi, ki uporabljajo .NET ogrodje, se namrec prevedejo v enak MSIL (MS intermediate language), neko vrsto assemblerja, ki jih potem JIT (just in time compiler) prevede v native kodo sistema, na katerem pac tece. V bistvu podobna zadeva kot pri Javi, vendar tam ponavadi aplikacije tecejo znotraj Java Virtual Machine-a, kar je sicer podobno, a pocasneje. Obstajajo pa tudi JIT za Javo, celo prevajalniki, ki prevedejo Java izvorno kodo v native strojno kodo za doloceno platformo, vendar je to ze druga zgodba.
Kar pa se tice tistega vprasanja o standardnih Windows knjiznjicah...mislim, da ze sam OS ne bi brez njih deloval
