Funkcija realloc() zagotavlja le to, da je novi pomnilnik zahtevane dolžine in vsebuje vse morebitne podatke s stare lokacije. Lokacija se seveda lahko spremeni (s povsem tehničnega stališča nobena implementacija ne more zagotavljati, da bo ohranila isti začetni naslov in omogočala poljubno večanje prostora).

Starih kazalcev v polje po klicu realloc() ni več varno uporabljati. Željeni učinek pa je še vedno mogoče doseči z dostopanjem do lokacij s pomočjo odmika od začetnega naslova. Ta se zaradi kopiranja starih podatkov seveda ohrani.

nasvet: ne uporabljaj realloc...ni pretirano varno. Ni namrec nujno, da ti ohrani stare podatke.
Predlagam ti, da naredis nekako takole:
uporabi c++, naredi razred DynamicArray in zacni...vanj daj instancno spremenljivko npr.: char * m_Buffer; in int m_Size;
nato pa dodas metodo za povecanje bufferja, ki bo videti nekako takole:








Koda:

private void DynamicArray::realloc(int pSize) {
  char * temp = new char[pSize];  // ustvari novi buffer

  memcpy(temp, m_Buffer, m_Size);  // skopira stari buffer v novega
  delete [] m_Buffer;
  m_Buffer = temp;
  m_Size = pSize;
}


Za dostopanje do bufferja v DynamicArray objektu pa overloadaj operator []. Na ta nacin ne bos imel tezav z naslovi, ker nikoli ne bos direktno dostopal do m_Buffer-ja. Ce to potrebujes za kaksne druge namene, kjer potrebujes direktni dostop do m_Buffer spremenljivke pa dodaj se metodo







Koda:

public const char * getBuffer() {
  return m_Buffer;
}


Vendar bos po vsaki realokaciji moral spremeniti vse reference, ki kazejo nanj. Istega naslova itak ne mores v nobenem primeru dobiti. Predlagam ti, da manj delas direktno s spremenljivkami, vedno preko nekih wrapper razredov.

Why reinvent the wheel?

V C++ je dinamičen array že izdelan in 100% prizkušen - std::vector. Poleg tega ne more iti v overflow, ker se njegova velikost dinamično povečuje. (Lahko gre sicer v underflow, ampak to lahko preprosto preveriš z lastnostjo size() in se temu izogneš). Poleg tega, z metodo at() dobiš tudi preverjanje meja (range checking), če pa tega nočeš zaradi kritičnosti pri hitrosti izvajanja, lahko preprosto uporabljaš operator [] kot pri navadnem arrayu.

Še primerček:








Koda:

#include <vector>
using namespace std;

vector<int> stevilke; // dinamični array, ki bo vseboval integerje

stevilke.push_back(1); // na konec arraya "pripnemo" številko 1
int i = stevilke[0]; // i pridobi vrednost 1, kot pri navadnem arrayu
int j = stevilke.at(0); // range-checked verzija prejšnjega klica
int k = stevilke.pop_back(); // iz arraya "potegnemo" stevilko 1 in jo priredimo spremenljivki k
//...
