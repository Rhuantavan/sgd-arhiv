Physics workshop

I've written a tiny little app showing some of the physical phenomena (such as light diffraction, refraction, horizontal throw (or how shall I name it) and water simulation based on simplified Navier-Stokes equations based on Yann Lombard lecture in 2003).

Some screenshots:

Application is totally written in Microsoft .NET 2.0 beta framework so if you'd like to test it you'll first have to go here. The file is quite big (about 24MB) and can take up to 2 hours to download for dial-up users, but it only needs to be installed ONCE. And once you have it installed, you don't have to download it again.

And to my classmates... If you really don't like to download .net framework (dunno why, though) you can stop me at school and ask me for CD or something and we'll try to work things out.

As for the application itself, it is rather humble in size (don't let me explain the technical part of this;)). And all you have to do is download the zip file (down somewhere) and run the executable. If it doesn't work (and you HAVE downloaded and installed .net framework) send me an email with an explanation to this address and we'll try to sort things out.

[download]

The problems might also occur to users with poor PC performance (especially water simulation is quite CPU demanding)..
I'd recommend something better then 1000MHz CPU, 128MB RAM, and Windows XP (but it really should work on windows 98 and up and older CPUs (I've tested it on 733MHz processor and it worked well).
