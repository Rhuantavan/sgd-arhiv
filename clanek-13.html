Drevesne strukture: Osnove

Avtor: snake
Objavljeno: 23.01.2003, ob 23:53:34.


Drevesa igrajo v programiranju zelo pomembno vlogo (pri podatkovnih bazah, grafičnem programiranju, umetni inteligenci,…). V nizu člankov bomo spoznavali različne tipe dreves in njihovo uporabo. Tokratni članek obsega osnove drevesnih struktur in krająo predstavitev sploąnih dreves.

Rekurzija

Rekurzija je zelo pomembno (in tudi zapleteno) poglavje o drevesih. Zakaj pravzaprav gre?

Programerski slovarji ta pojem razlagajo takole:

Rekurzija: glej Rekurzija

Bistvo rekurzije je v tem, da rekurzivna funkcija kliče sama sebe. Poleg tega pa lahko z rekurzijo problem razdelimo na več podproblemov, kar lahko znatno pospeąi reąevanje zadanega problema.

Kako se vse to naredi?

Vsaka rekurzivna funkcija je sestavljena iz rekurzivnega dela (dela kjer kaľe sama nase) in terminacijskega dela. Terminacijski del je pomemben zato, ker bi se drugače rekurzivna funkcija ponavljala v neskončnost. To so za nas najpomembnejąe lastnosti rekurzije.

Neskončnosti izvajanja rekurzije pa ne potekajo točno tako, kot je navedeno v prejąnjem odstavku. Rekurzija si namreč ob vsakem izvajanju dodeli nek prostor v spominu (stack). Ko je spomin poln, pride do t.i. "stack overflowa" in funkcija se konča. Prostor, ki ga funkcija zapolni ob vsakem izvajanju, vsebuje informacije o stanju funkcije. Tako se lahko v kateremkoli trenutku vrnemo na katerokoli stanje, kjer se je rekurzivna funkcija nahajala. Tukaj se skriva naąa ključna informacija.

Poglejmo primer rekurzivnega in nerekurzivnega reąevanja problema:

1.:  void izpisi_stevilo_rekurzivno( int stevilo )
2.:  {
3.: 	cout << stevilo << endl;
4.: 	if ( stevilo == 0 )
5.: 		cout << "Konec rekurzijske funkcije\n";
6.: 	else
7.: 	{
8.:  		izpisi_stevilo_rekurzijsko( stevilo - 1 );
9.: 	}
10.: }

vrstica 3: izpiąemo ątevilo
vrstica 4: terminacijski del (preverjamo ali smo z odątevanjem ľe priąli do 0), če smo, izpiąi tekst (vrstica 5)
vrstica 8: če ąe nismo končali, ponovno začni naąo rekurzivno funkcijo (to je rekurzivni del).

In ąe nerekurzivno (z iteracijo):

1.: void izpisi_stevilo( int stevilo )
2.: {
3.:	while( stevilo != 0 )
4.:	{
5.:		cout << stevilo << endl;;
6.:		stevilo--;
7.:	}
8.:	cout << "Konec nerekurzijske funkcije\n";
9.: }

vrstica 3: terminacijski del
vrstica 5: izpiąemo ątevilo
vrstica 6: zmanjąamo ątevilo in ponovimo zanko.

V takąnih primerih rekurzije ne bomo uporabili, saj ima kar nekaj slabosti (je nekoliko počasnejąa, poleg tega pa se ne more ponavljati v neskončnost).

Pomembno: rekurzivna funkcija si dodeljuje prostor v spominu, kjer shranjuje podatke o njenih prejąnjih stanjih.

Spoznali ste osnove rekurzij. Več informacij lahko najdete na http://www.google.com

Drevesa

Pri programiranju se uporablja več vrst drevesnih struktur. Drevesne strukture se uporabljajo za iskanje po bazah podatkov ("2-3 trees", "2-3-4 trees", "AVL trees", "red-black trees",…), pri 3D grafiki ("BSP trees", "OCtrees", "quad trees",…), sploąnem game programmingu (minmax, pathfinding trees,…), datotečnih sistemih, stiskanju podatkov,… Vseh teh pa si zaenkrat ąe ne bomo ogledali.

Najosnovnejąi primer predstave drevesa:

Vsak krog predstavlja eno vozliąče (node). V tem primeru bi lahko kateregakoli izmed vozliąč proglasili za izhodiąčnega (root node). Zato bolj pogosto uporabljamo poseben razred, ki kaľe na eno vozliąče, ki predstavlja izhodiąče.

Deli drevesa

Kot ľe omenjeno je drevo sestavljeno iz vozliąč. Začetno vozliąče se imenuje root node. če ima izhodiąčno vozliąče pod sabo ąe kakąnega, se "spodnji" imenuje child node (hčerinsko vozliąče), "zgornji" pa je v takem primeru parent node (starąevsko vozliąče). Vozliąče, ki nima hčerinskega vozliąča, se imenuje leaf node.

Poglejmo primer:

Vozliąče 1 je izhodno (in hkrati starą vozliąč 2, 3 in 4). Vozliąče 2 je hčerinsko voliąče vozliąča 1 in starą vozliąč 5 in 6. Vozliąče 3 je hčerinsko vozliąče vozliąča 1 in starą vozliąča 7. Vozliąče 4 je hčerinsko vozliąče vozliąča 1, obenem pa je tudi leaf node, saj nima hčerinskega vozliąča.
Drevo lahko ima tudi poddrevesa. V naąem primeru bi lahko določili, da je vozliąče 2 izhodiąčno vozliąče poddrevesa.
Sedaj pa se mi ľe vozlajo prsti! :-]

Drevesna urejenost

Poleg vseh starąevsko-hčerinskih zadev, lahko drevesa razdelimo tudi na viąinske stopnje (Height Levels). Izhodiąčno vozliąče je ničelne stopnje (ali prve, odvisno od naąega ątetja), vsako hčerinsko vozliąče pa je za eno stopnjo viąje kot je njegov starą.

Osvojili smo osnovno teorijo, sedaj pa h konkretnim drevesom…

V praksi

Verjetno sploąnega drevesa v igrah ne boste uporabljali z namenom predstavljanja izvora svoje druľine. V igrah se sploąna drevesa največkrat uporabljajo v procesih odločanja (umetna inteligenca).

Na primer:

Računalniąki igralec vas zagleda, kako plezate čez most, da bi zavzeli njegovo bazo.

To bi bil eden najosnovnejąih (in zelo kratkih) primerov odločanja. V igrah se pojavljajo veliko bolj zapletena in večja drevesa.
