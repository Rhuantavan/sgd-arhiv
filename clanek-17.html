DX9 + VB.NET tutorial: Izris 2D objektov v 3D načinu

Avtor: Kavan
Objavljeno: 12.02.2003, ob 17:08:17.


Tokrat si bomo ogledali, kako v Direct3D izrisujemo 2D objekte. Najprej si bomo ogledali enostavni princip, ki je dober za enostavne primere, nato pa ąe malo zahtevnejąi, ampak zato tudi hitrejąi način izrisa.

Za primere bomo uporabljali teksturo text.dds, na kateri so narisane črke abecede. Tekstura uporablja alpha kanal, ki določi katere stvari so dejansko vidne (prosojnost), tako da se bodo pri izpisu videle le črke in ne tudi kvadratki okrog njih.

Preskočimo inicializacijo, ki si jo lahko pogledate v priloľenem projektu, in pojdimo na naą enostavni primer, ki uporablja objekt imenovan Sprite. Objekt inicializiramo takole (kjer je dev naą Direct3D Device):

spr = New Sprite(dev)

Znotraj dev.BeginScene(), dev.EndScene() bloka pokličemo spr.Begin(). Ta klic postavi vse potrebne render state nastavitve, ki jih potrebuje Sprite za izrisovanje. Zdaj lahko začnemo risati vse naąe 2D stvari, zato si oglejmo kaj vse nam ponuja Sprite.

Public Sub Draw( _
    ByVal srcTexture As Texture, _
    ByVal srcRectangle As Rectangle, _
    ByVal scaling As Vector2, _
    ByVal rotationCenter As Vector2, _
    ByVal rotation As Single, _
    ByVal translation As Vector2, _
    ByVal color As Color _
)

srcTexture – tekstura, ki jo ľelimo izrisati
srcRectangle – pravokotnik, ki pove kateri del teksture ľelimo izrisati
scaling – factor raztega v x in y smeri
rotationCenter – okrog katere točke na teksturi bomo vrteli
rotation – za koliko radianov bomo zavrteli
translation – kam ľelimo izrisati naą del teksture
color – barvni in alpha kanal se pomnoľita (modulirata) s to vrednostjo
(lahko vnesemo tudi kot heksadecimalno vrednost, npr. &HFFFFFFFF)

Na koncu, ko smo vse izrisali ąe povrnemo stanje v kakrąno je bilo pred začetkom izrisa s klicom spr.End().

Oglejmo si zdaj en primer, ki izriąe del teksture, kjer je črka A:

Private Sub DrawSprite1()
    spr.Begin() 'priparvi device za izris sprite-ov
    'izriąemo del teksture med (0,0) in (8,20)
    'brez raztega, rotacije, translacije
    spr.Draw(tex, New Rectangle(0, 0, 8, 20), New Vector2(1, 1), New Vector2(0, 0), 0,
       New Vector2(0, 0), Color.White)
    spr.End() 'obnovi stanje, ki je bilo pred klicem Sprite.Begin
End Sub

Ostale primere, ki prikazujejo uporabo ostalih parametrov na primeru spreminjanja parametrov skozi čas (animacija), si poglejte v priloľenem projektu.

Zdaj pa si poglejmo kaj storiti v primeru, da je Sprite prepočasen za naąe potrebe. Kot prvo je pomembno, da imamo čim manj tekstur. V ta namen se velikokrat uporablja teksture, na katerih so vsi elementi potrebni za izris (npr. različni tile-i za različna ozemlja zloľeni na eno večjo teksturo). Kot naslednjo stvar se moramo spoznati z dinamičnimi vertex bufferji. Le ti se uporabljajo v primerih, ko se ves čas spreminja kar izrisujemo (se pravi nimamo statične geometrije).

Tokrat bomo uporabljali CustomVertex.TransformedColoredTextured za podajanje geometrije. Gre za točke, ki so transformirane. Torej niso podane v 3D prostoru, temveč v 2D prostoru ekrana. Če je naąa resolucija 800×600, potem so vrednosti za x med 0 in 800 ter za y med 0 in 600. Zdaj si ustvarimo ľeljen VertexBuffer.

vb = New VertexBuffer(GetType(CustomVertex.TransformedColoredTextured),
         MaxVertices, dev, Usage.WriteOnly Or Usage.Dynamic,
         CustomVertex.TransformedColoredTextured.Format, Pool.Default)

Zraven imejmo ąe array iste velikosti, kjer bomo gradili naąe podatke:

Private vl(MaxVertices - 1) As CustomVertex.TransformedColoredTextured

Najprej si oglejmo, kako polniti buffer in izrisovati stvari, kasneje pa si bomo ąe pogledali kako nastaviti podatke za posamezen pravokotnik. Groba skica je taka:

With dev
   .SetTexture(0, tex) 'nastavimo teksturo
   .VertexFormat = CustomVertex.TransformedColoredTextured.Format 'nastavimo format vertex-ov
   .SetStreamSource(0, vb, 0) 'nastavimo vertex buffer

   For Each ... In ...
   'nastavimo podatke za en rectangle
   '...izpuąčeno
   numTriangles += 2 'vsak pravokotnik sestavimo iz dveh trikotnikov

   If numTriangles * 3 > MaxVertices - 6 Then
       'napolnili smo dovolj podatkov za celoten buffer
       'poąljemo podatke v vertexbuffer
       vb.SetData(vl, 0, LockFlags.Discard)
       'izriąemo vse v bufferju
       dev.DrawPrimitives(PrimitiveType.TriangleList, 0, numTriangles)
       'resetiramo indekse v naą lokalni array
       numTriangles = 0
       iv = 0
   End If
   Next

   'izriąemo ąe preostale trikotnike
   vb.SetData(vl, 0, LockFlags.Discard)
   If numTriangles > 0 Then
       dev.DrawPrimitives(PrimitiveType.TriangleList, 0, numTriangles)
   End If
End With

Pri vsem tem je bistveno omeniti le uporabo LockFlags.Discard, ki pove da starih podatkov v bufferju ne rabimo več (ta flag lahko uporabljamo samo pri dinamičnih bufferjih). Sledi nastavljanje podatkov za posamezni pravokotnik:

vl(iv) = New CustomVertex.TransformedColoredTextured(New Vector4(sx + 0 - 0.5F, sy + h - 0.5F, 0.9F, 1.0F), intColor, tx1, ty2) : iv += 1
vl(iv) = New CustomVertex.TransformedColoredTextured(New Vector4(sx + 0 - 0.5F, sy + 0 - 0.5F, 0.9F, 1.0F), intColor, tx1, ty1) : iv += 1
vl(iv) = New CustomVertex.TransformedColoredTextured(New Vector4(sx + w - 0.5F, sy + h - 0.5F, 0.9F, 1.0F), intColor, tx2, ty2) : iv += 1
vl(iv) = New CustomVertex.TransformedColoredTextured(New Vector4(sx + w - 0.5F, sy + 0 - 0.5F, 0.9F, 1.0F), intColor, tx2, ty1) : iv += 1
vl(iv) = New CustomVertex.TransformedColoredTextured(New Vector4(sx + w - 0.5F, sy + h - 0.5F, 0.9F, 1.0F), intColor, tx2, ty2) : iv += 1
vl(iv) = New CustomVertex.TransformedColoredTextured(New Vector4(sx + 0 - 0.5F, sy + 0 - 0.5F, 0.9F, 1.0F), intColor, tx1, ty1) : iv += 1

Najprej pomen spremenljivk: sx in sy določata pozicijo kamor bomo izrisali pravokotnik, w in h sta ąirina in viąina pravokotnika, intColor je barva s katero so tekstura modulira, tx1, ty1, tx2, ty2 pa so zgornja leva in spodnja desna koordinata pravokotnika na teksturi, ki ga ľelimo izrisati. Pri tem sta sx in sy kot omenjeno zgoraj med 0 in 800 ter 0 in 600 oziroma v takem obsegu kot ga določa velikost naąega okna. w in h sta prav tako izraľena v pixlih. Le tx1, ty1, tx2, ty2 so izraľeni v deleľu od 0 do 1. Kot se da razvideti iz zgornjega primera smo povsod odąteli 0.5. To storimo zato, da doseľemo direktno mapiranje texlov na pixle. Za podrobnejąo razlago si preberite poglavje Directly Mapping Texels to Pixels v DirectX SDK-ju. Prav tako se tukaj ne bi spuąčal v pomen z in w koordinate pri TransformedColoredTextured tipu vertex-ov. ©e dodatna izboljąava pri zgoraj opisanem postopku bi bila uporaba statičnega index bufferja, tako se nam ne bi podvajale točke v naąem vertex bufferju.

Za konec ąe povzemimo vse skupaj. Če ľelimo le izrisati nekaj 2D stvari na zaslon je najlaľje uporabiti Sprite. Če pa naą pogon izključno temelji na izrisu velikih ątevil 2D objektov, pa je smiselno razmisliti o zadnji metodi, ki bo zadostovala v praktično vseh primerih.
